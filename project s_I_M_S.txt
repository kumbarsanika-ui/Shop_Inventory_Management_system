Build a complete, professional, scalable full-stack application using:

* Frontend: React.js
* Backend: Node.js
* API Framework: Express.js
* Database: MySQL
* API Testing: Postman
* Architecture: MVC + Service Layer + Repository/Data Access Layer
* Authentication: JWT
* Password Security: bcrypt
* Authorization: Role-Based Access Control (RBAC)

The application must be beginner-friendly but follow production-style architecture and coding practices.

==================================================

1. ARCHITECTURE
   ==================================================

Follow this backend architecture:

Client
↓
React
↓
REST API
↓
Express Routes
↓
Middleware
↓
Controller
↓
Service
↓
Repository
↓
MySQL
↓
Repository
↓
Service
↓
Controller
↓
JSON Response

IMPORTANT:

* Routes handle endpoint definitions.
* Controllers handle HTTP request and response.
* Services contain business logic.
* Repositories contain database queries.
* Models represent database entities/data structures.
* Middleware handles authentication, authorization, validation and errors.
* Controllers must NOT contain SQL queries.
* Services must NOT directly handle req/res.
* Repositories must NOT contain business logic.
* Use async/await.
* Use centralized error handling.
* Use reusable utilities.
* Use environment variables.
* Never hard-code credentials.
* Use parameterized SQL queries.
* Use MySQL transactions for multi-table operations.
